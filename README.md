# Дашборд клева ручьевой форели

## Как открыть

Открой файл:

```text
app/index.html
```

## Как пользоваться

Открой [дашборд](https://xenobiotik.github.io/trout-dashboard/app/). Свежая погода загружается автоматически.

Кнопка `Обновить погоду` повторяет запрос. Вверху показано время обновления по Москве.
Если источник недоступен, используется последний успешный прогноз не старше 6 часов с явным предупреждением.
Просроченные данные скрываются. Открытая страница автоматически запрашивает обновление после часа и при возвращении сети.
Саму страницу без сети впервые открыть нельзя: полноценного офлайн-приложения пока нет.

## Ручное обновление сохраненных live-данных

Этот способ больше не обязателен для обычного пользования, но полезен как запасной вариант:

1. дважды нажать `Обновить погоду.command`;
2. дождаться сообщения `Готово`;
3. обновить страницу дашборда.

Альтернативно через терминал:

```bash
cd "/Users/xenobiotik/Desktop/Codex/trout-dashboard"
node src/updateLiveData.js
```

## Своя точка

Во вкладке «Своя точка» можно ввести широту и долготу и получить
тот же пятидневный прогноз по семи факторам. Например: `60.557705, 30.253624`.
Также принимаются координаты через пробел и десятичные запятые с разделителем `;`.
Градусы, минуты и секунды пока не поддерживаются. Широта всегда идет первой.

Сезонная модель предназначена для Ленинградской области и юга Карелии. В интерфейсе
действует техническая рабочая область 58–63° с. ш., 27–36° в. д. Это приблизительная
граница применения, не административный контур и не научно установленная граница.
За ее пределами расчет не запускается: перенос сезонной модели на другой климат
требует отдельной адаптации. Координаты сами по себе не подтверждают наличие ручья или форели.

Одно свое место сохраняется в браузере и восстанавливается при следующем открытии.
Новый расчет заменяет сохраненное место; кнопка «Удалить точку» убирает его и его прогноз.
Пять исходных районов не изменяются. Настройки не синхронизируются между устройствами.
Для запроса погоды координаты передаются Open-Meteo.
Координаты пользователя не записываются в GitHub или адрес страницы. Общего реестра
посетительских точек нет. Ранее сохраненные координаты восстанавливаются; старое название не используется.

Прогноз точки хранится отдельно от районов, привязан к точным введенным координатам
и проходит те же проверки возраста и полноты. При потере сети допускается только
свежая сохраненная оценка этой же точки с явным предупреждением. Старый или чужой
прогноз не подставляется. Вода, прозрачность и уровень остаются косвенными оценками.
Все даты и временные окна используют московское время.

Версия интерфейса: 0.8. Расчетная модель и веса: 0.6, без изменений.
Сайт и локальный скрипт используют общий расчетный модуль `app/online-engine.js`.
Семь весов: температура воды 30%, сезон 20%, изменение погоды 15%, прозрачность 12%,
освещенность 12%, водный режим 6%, ветер 5%. Динамика давления занимает до 5 баллов
внутри изменения погоды. Абсолютное давление и Луна отдельных вкладов не имеют.
Итог равен округленной сумме вкладов. Предупреждения о жаре и паводке показаны отдельно.
Индекс не является вероятностью улова и требует проверки по журналу реальных выездов.

## Уверенность, даты и бережное отношение

«Уверенность модели» сопровождается пояснением: это условная отметка, не измеренная
точность прогноза. Средняя означает косвенную оценку воды по погоде; низкая возникает
при неполных данных, обильных осадках, предполагаемой сильной мутности или риске паводка.
Текущая модель не присваивает высокую уверенность. Балл индекса и уверенность независимы.
Во всех видимых датах указан сокращенный день недели, в московском времени.

В рекомендациях постоянно показаны ограничения для природных водоемов Ленобласти
и Карелии, просьба немедленно отпускать случайно пойманную запрещенную рыбу и совет
использовать одинарные безбородые крючки при разрешенной ловле. Совет об отпускании
не означает разрешения на целенаправленную ловлю запрещенного вида.

Для выбранной даты с 20 сентября по 30 ноября показывается предосторожное предупреждение
о нересте с просьбой не заходить в воду у гнезд; с 1 декабря по 30 апреля оно заменяется
напоминанием об икре и личинках в грунте. Это экспертные окна, не сроки из нормативного
акта и не наблюдение нереста в конкретном ручье. При отсутствии прогноза используется
сегодняшняя московская дата. Ограничения остаются видны при любой погоде и без загрузки данных.

Источники и границы этих рекомендаций: [памятка об ограничениях](docs/fishing-care.md).
