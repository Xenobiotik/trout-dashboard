# Дашборд клева ручьевой форели

## Как открыть

Открой файл:

```text
app/index.html
```

## Как пользоваться

Открой [дашборд](https://xenobiotik.github.io/trout-dashboard/app/). Свежая погода загружается автоматически.

Кнопка `Обновить погоду` повторяет запрос. Вверху показано время обновления по Москве.
Если источник недоступен, используется последний успешный прогноз не старше 6 часов с явным предупреждением.
Просроченные данные скрываются. Открытая страница автоматически запрашивает обновление после часа и при возвращении сети.
Саму страницу без сети впервые открыть нельзя: полноценного офлайн-приложения пока нет.

## Ручное обновление сохраненных live-данных

Этот способ больше не обязателен для обычного пользования, но полезен как запасной вариант:

1. дважды нажать `Обновить погоду.command`;
2. дождаться сообщения `Готово`;
3. обновить страницу дашборда.

Альтернативно через терминал:

```bash
cd "/Users/xenobiotik/Desktop/Codex/trout-dashboard"
node src/updateLiveData.js
```

## Проверки и модель

```bash
node --test tests/model.test.cjs
```

[Пособие для рыболова с источниками](docs/methodology.pdf) объясняет основания индекса.
[Правила модели 0.6](docs/model-v0.6.md) описывают веса, окна данных, шкалы и пропуски.
Сайт и локальный скрипт используют общий расчетный модуль `app/online-engine.js`.
Семь весов: температура воды 30%, сезон 20%, изменение погоды 15%, прозрачность 12%,
освещенность 12%, водный режим 6%, ветер 5%. Динамика давления занимает до 5 баллов
внутри изменения погоды. Абсолютное давление и Луна отдельных вкладов не имеют.
Итог равен округленной сумме вкладов. Предупреждения о жаре и паводке показаны отдельно.
Индекс не является вероятностью улова и требует проверки по журналу реальных выездов.
